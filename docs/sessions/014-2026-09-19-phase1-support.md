   PLUS 3 historical entries → 4 total (rec-seed-01..04, all past days).
   `rec-seed-04` references an archived task (`task-thermo-00`) — journals
   are append-only history; documented in `_meta.journalNote`.
3. **Test database = `harbour_test`** on the same Postgres server (dropped/
   recreated/migrated per test session) — the monitor's prompt allowed a
   test schema; a separate DB is cleaner isolation and equally "the same
   DB server". Documented in the conftest docstring.

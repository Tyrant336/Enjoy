## Deviations & ambiguities (for the monitor)

1. `POST /agents/flashcards/review/start` — contract amendment carried from
   session-of-record (handoff §3); still awaiting ratification.
2. Labels chat command handled client-side (§5.3 has no label-toggle event) —
   documented in handoff, implemented in ChatPanel only (one place).
3. Skip tour = dismiss endpoint (emits tour_end) — documented in handoff.
4. **NEW — overlap with T's `WorldOverlays.tsx`:** it already renders a tour
   offer, a Skip pill (local `endTour()` only — does NOT POST dismiss, so the
   server-side `pendingTour` would survive a skip), and the world-error banner.
   TourUI/Banners render the same concerns from uiStore. **Recommendation:**
   in Phase 3 mount TourUI + Banners (production-correct: Skip POSTs dismiss)
   and have T strip the offer/Skip/error pills from WorldOverlays (keeping the
   notice pill + review "Return to harbour"), OR drop TourUI's offer/skip and
   extend hostHandlers with an onSkipTour. Do not mount both as-is.
5. **NEW — gap risk:** `worldStore` (T) has no rebuild-from-`WorldState` hook;
   on SSE gap/reconnect the worldBus refetch rebuilds **uiStore only**
   (`onWorldState`), so the 3D projection can drift across a gap (e.g. missed
   spawn_boat). Frozen `WorldApi` has no rebuild method. Flag for monitor/T —
   Phase 3 decision (T adds a rebuild action, or the bus replays from
   `lastEventSeq` instead of skipping).
6. ChatPanel refetches world-state when a chat response contains a plan (so
   TaskSheet sees it without waiting for a reconnect) — small, documented here.
